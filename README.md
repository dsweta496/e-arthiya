# e-Arthiya

A farmer-first digital marketplace that connects farmers and FPOs
with multiple buyers through competitive offers and transparent
transaction records.

## MVP

- Assisted farmer/FPO onboarding
- Produce lot creation
- Buyer discovery
- Competitive bidding
- Verified external/local offers
- Farmer-controlled offer selection
- Purchase commitments
- Blockchain-backed transaction records

## Technology

- React
- Node.js
- Express.js
- MongoDB
- Solidity
- Hardhat
- Ethers.jsv
