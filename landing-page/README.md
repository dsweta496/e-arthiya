# Team Swae landing page

Static responsive landing page for HACKX National Hackathon Grand Finale / WIE International Leadership Summit '26.

## Local preview
Open `index.html` directly in a browser, or use VS Code Live Server.

## Add your links
In `index.html`, replace the four `href="#"` values with the public URLs for:
1. GitHub repository
2. Demo video
3. Round 2 presentation
4. Digital poster

## Render deployment
Create a **Static Site** connected to the existing `e-arthiya` GitHub repository:
- Branch: `main`
- Root Directory: `landing-page`
- Build Command: leave blank
- Publish Directory: `.`

The root directory is set to `landing-page`, so `.` means the landing-page folder itself.
